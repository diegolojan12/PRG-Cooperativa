Constitución de SUMA · VII. Arquitectura

SUMA es una aplicación cliente-servidor de tres capas. El cliente es una SPA en Angular, instalable como aplicación web progresiva. El servidor es una API REST en Node.js con NestJS, y los datos se guardan en PostgreSQL. Las tres capas son independientes; en el laboratorio cada una puede correr en una computadora distinta.
