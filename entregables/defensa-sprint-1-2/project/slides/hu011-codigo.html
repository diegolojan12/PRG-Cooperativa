El dominio impide el dictamen inválido

Dominio · dominio/referidos.mjs

#dictaminar(estado, fechaDecision, estadoCuenta) {
  if (this.estado !== 'PENDIENTE')
    throw errorDeDominio('Solo se dictaminan
      referidos en estado Pendiente.', 409);
  if (estado === 'APROBADO' &&
      !CuentaCooperativa.estaAprobada(estadoCuenta))
    throw errorDeDominio('La cuenta vinculada
      del referido debe estar Aprobada.', 409);
  Object.assign(this, { estado, fechaDecision });
} // RF-11-4

RESULTADO

Si dos administradores dictaminan el mismo referido a la vez, uno recibe 200 y el otro 409: los puntos se acreditan una sola vez por persona.

backend/src/dominio/referidos.mjs:55 · backend/src/api.mjs:1097 · frontend/src/app/features/referidos/referidos.page.ts

La regla de negocio vive en la clase Referido: no se puede dictaminar algo que no esté pendiente, ni aprobar sin la cuenta vinculada aprobada. La ruta lo ejecuta todo en una transacción: actualiza el estado, acredita los puntos a ambas personas, registra la bitácora y notifica. Si dos administradores dictaminan a la vez, uno recibe 200 y el otro 409. (40 s)
